设计原则

  1. 双引擎显式可见：每张概率卡同时显示市场隐含概率、行为金融合成概率、AI 合成概率与最终融合概率。
  2. 数据透明：所有数据来源 / 样本量 / 计算时间戳 / 置信区间必须可见。
  3. 本地优先：所有计算在前端 + Tauri Rust 后端，不依赖云服务。
  4. 键盘优先：常用操作（切换主题、跳转市场、确认下单）提供快捷键。
  5. 三主题一致：dark / light / matrix 共享同一布局，仅替换色板与字体。
