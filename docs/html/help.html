▦ 入门 · 5 分钟上手 Polyrocket

Polyrocket 是一个本地优先的足球预测市场交易终端，核心是基于"双引擎"的概率融合系统：

  1. 逻辑一 · 行为金融（Behavioral） — 通过 HHI 集中度、聪明钱分歧、z-score / Bollinger Bands 等行为金融指标对市场隐含概率做修正。
  2. 逻辑二 · 多因子 AI（Multi-Factor AI） — 调用 LLM（GPT-4o / Claude / DeepSeek）综合阵容、伤停、xG、控球率、盘口等多因子，给出独立概率。
  3. 融合（Fusion） — 两套引擎的输出通过贝叶斯加权 + 温度缩放融合成最终概率（fused）。

推荐开始顺序：① 完成 Onboarding ② 浏览 Dashboard 了解今日比赛 ③ 打开感兴趣的 Market Detail 查看融合概率 ④ 在 Bankroll 设置风险偏好 ⑤ 配置 Notifications。

⌬ 术语表

理解 Polyrocket 的核心概念。所有术语在文档和 UI 中均保留英文。

HHIHerfindahl-Hirschman Index

衡量市场持仓集中度的指标。范围 0~1，越高表示某一方持仓占比越大，越低表示分散。> 0.5 视为高度集中，需警惕操纵。

z-score标准分数

价格偏离均值的标准化度量。z = (x - μ) / σ。|z| > 2 视为越界，可触发均值回归（fade）信号。

Bollinger布林带

以 20 日均线为中轨，上下 2σ 分别为上轨、下轨。价格触及下轨后 14 天内有 71% 概率回归中轨。

Fuse融合

将 L1（市场）+ L2（行为金融）+ L3（AI）的概率通过贝叶斯加权合成最终概率，并附置信度。

Edge优势

融合概率与市场隐含概率的差值（以 ¢ 计）。Edge > 5¢ 视为显著优势，可考虑建仓。

BrierBrier Score

概率校准指标。BS = (p - y)²，对所有结果求均值。0 为完美，越小越好。基准 BaseRate 模型约 0.25。

Kelly凯利公式

f* = (bp - q) / b，其中 b 为盈亏比，p 为胜率，q = 1-p。建议使用 1/4 Kelly 以降低波动。

Sharpe夏普比率

年化收益 / 年化波动率。> 1 为合格，> 2 为优秀。目标 ≥ 1.5。

VaRValue at Risk

在给定置信水平下的最大可能损失。如 VaR(95%) = $1,840 意味着 95% 概率日亏损不超过 $1,840。

MDD最大回撤

账户净值从峰值到谷底的最大跌幅。< 15% 视为可控。

xG预期进球

基于射门质量的统计模型给出的"应进球数"。xG 差 = 己方 xG - 对手 xG，正值越大越有利。

LP流动性提供者

在 AMM 中提供资金以获得手续费的地址。LP 持仓变化是大单流入 / 流出的领先指标。

◈ 故障排查

Q: 打开应用后侧栏一直显示 "Tauri 1.6 · connecting"

检查 Tauri 后端是否启动。macOS: launchctl list | grep polyrocket · Windows: 查看任务管理器。如果未运行，删除 ~/.polyrocket/lock 后重启应用。

Q: LLM 调用一直超时

前往「设置 → 网络」检查 HTTPS 代理设置。如果你使用公司网络，可能需要关闭代理；如果你使用 OpenAI API 但在中国大陆，请配置 VPN 出口。

Q: 为什么我的融合概率和 AI 概率完全一样？

说明 Behavioral 引擎和市场隐含完全一致。这种情况通常发生在开盘 30 分钟内，市场尚未形成分歧。可前往「Model Lab」查看校准曲线。

Q: 下单一直 pending 不成交

检查订单簿深度（Market Detail → 订单簿）。如果挂单价远离中价，订单会一直在队列末尾。可调整过期时间到 IOC 立即成交。

Q: 主题切换后界面错乱

这是 _shell.js 的小问题。刷新页面（⌘R）即可。后续会修复为不刷新的渐变切换。

Q: 数据如何重置？

「设置 → 数据 → 重置所有数据」会清空 SQLite 数据库。系统会重新拉取链上事件。强烈建议先导出备份。

Q: 如何完全离线运行？

前往「LLM Mgmt」启用 Ollama / qwen2.5-7b。开启后系统会在网络故障时自动回退到本地模型。注意：本地模型准确度较云端低 8-12 pp。

Polyrocket 是一个由社区驱动的开源项目，致力于为足球预测市场提供专业级的本地交易终端。 核心理念是"双引擎融合"：既不盲从群体智慧，也不迷信单一 AI，而是让两者互相校准。
