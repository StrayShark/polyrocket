为什么需要 LLM？

基本面研判

把阵容、伤停、赛程密度、历史交锋盘口等结构化字段喂给 LLM，让其以教练视角做出综合判断。

多模型辩论

GPT-4o / Claude / DeepSeek 三方独立出价，若分歧过大则触发 高不确定性 标记，规避盲目下注。

本地优先

Ollama / vLLM 本地推理完全离线运行，你的 key 永远不离开本机。
